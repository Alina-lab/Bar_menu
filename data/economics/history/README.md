# История экономики: этапы 1–3

Данные в stage3_snapshot.zip относятся к прежней модели и **не используются текущим расчётом**. Архив сохраняет 62 файла с исходными относительными путями: старые рецептуры, цены, A/B/C/B2, расчёт по 1 л, Notebook, отчёты, графики, код и тесты. Их SHA256 закреплены в manifest.json. Исходная база отзывов осталась в прежних путях основного репозитория и защищена source_baseline.json.
