# Данные и метод исследования

## Источники и единицы наблюдения

Изучались меню и публичные отзывы о барах, рюмочных и ресторанах Санкт-Петербурга. Сохранены 43 карточки заведений; актуальный срез ограничен 30. Источники — Яндекс Карты, Restoclub, 2ГИС, Tripadvisor, Т-Банк Отзывы и отдельные перепубликации. Нового сбора в этой версии нет.

[Исходная книга](../data/nastoyki_reviews.xlsx) сохраняет заведения, отзывы, обезличенных авторов, упоминания, конкурентное меню, словарь вкусов и журнал источников. URL, даты обращения, локаторы публикаций и статусы проверки позволяют вернуться к свидетельствам. Страница списка отзывов не считается прямой ссылкой на комментарий.

Один отзыв — одна публикация; разные вкусы из неё записаны отдельными упоминаниями. Филиалы имеют разные ID. В проверенный срез входят публикации `source_status=verified`, без `duplicate_of`; в конкретный вкусовой срез — связанные с ними проверенные упоминания `specificity=concrete`.

В книге 368 публикаций, 358 проверены. Подтверждены 198 конкретных упоминаний из 108 отзывов, 114 нормализованных названий. Неподтверждённые строки сохранены и исключены из этих итогов. Публичный скрипт повторяет подсчёт по книге, не меняя её.

Строгий срез требует высокой уверенности разметки, выбранного актуального заведения, отсутствия отметки площадки `not_passed` и флага подозрительных/повторяющихся формулировок. В нём 143 упоминания из 84 отзывов. Это не новая проверка источников и не фильтр только по свежим датам.

## Нормализация и оценки

Исходное название сохраняется рядом с нормализованным. Явные синонимы объединяются; банан, банан-кокос и банановые сливки остаются разными продуктами. Общий ингредиент не делает сочетания одинаковыми.

Положительной считается явная оценка конкретной настойки. Перечень заказанного и высокая оценка заведения не переносятся на каждый вкус. Различаются положительные, отрицательные, смешанные, нейтральные оценки и простое упоминание.

[flavor_summary.csv](../data/flavor_summary.csv) — итоговая сводка завершённого исследования. Один отзыв/общее событие даёт не более одной оценки одного вкуса; противоречивые оценки объединяются в смешанную. Поэтому число строк упоминаний и база оценок могут различаться. Рядом показаны уникальные отзывы, заведения и база явно оценённых; их нельзя суммировать как независимых гостей.

У хреновухи и щавеля по семь упоминаний и по пять положительных оценок. У простой томатной все шесть положительных упоминаний относятся к одному заведению; в строгом срезе остаётся одно. Малые и сосредоточенные базы не дают общегородского рейтинга.

## Авторское решение и экономика

Финальные десять вкусов, восемь основных по 250 ₽ и два премиальных по 300 ₽ за 50 мл выбраны автором. Отзывы помогли изучить ассортимент, но не доказали оптимальность состава. Клюква сохранена автором при отсутствии подтверждённых положительных оценок в текущей базе.

[menu_economics.csv](../data/menu_economics.csv) содержит только итоговые показатели десяти позиций: названия, уровни, цены, плановый выпуск и сырьевые затраты. Исключены составы, дозировки, выход исходной рецептурной партии, коэффициенты масштабирования и технологии. Значения перенесены из завершённой модели; деньги не округлялись перед суммированием.

[menu_raw_material_costs.csv](../data/menu_raw_material_costs.csv) перенесён из существующей общей закупочной таблицы. Это потребность 16 ингредиентов, поставщики, фасовки, применённые цены, расходы и остатки. Источник цен — авторский сценарий 16.10.2026. Распределения ингредиентов по отдельным напиткам нет.

Первоначальная закупка — платёж за целые упаковки, использованное сырьё — производственный расход. Остаток сырья — 3 645,19 ₽; пригодность повторного использования не предполагается автоматически. Итоги получены из неокруглённых затрат десяти позиций. Сумма отдельно округлённых строк может отличаться на копейки.

План — 60 л и 1 200 порций. Потенциальная выручка 312 000 ₽ предполагает полную продажу по заданным ценам. Разница с израсходованным сырьём не является чистой прибылью. Выходы не измерены, закупочные условия требуют подтверждения. Безопасный срок хранения молочной настойки не установлен в рамках проекта.

## Ограничения и воспроизведение

Отзывы исторические и неравномерные; у 275 из 358 проверенных публикаций доступен только видимый фрагмент. Проверка текста не доказывает реальность визита. Пишущие отзывы не представляют всех гостей, упоминания не измеряют продажи. Пол и возраст неизвестны; прямое сообщение о приезде есть лишь в пяти отзывах, поэтому демографические выводы не делаются.

На Python 3.12:

```bash
python -m pip install -r requirements.txt
python scripts/portfolio.py
python -m pytest -q
python scripts/portfolio.py --check
```

Скрипт собирает PDF и PNG из опубликованного меню. `--check` проверяет повторную сборку и выполняет Notebook в новом ядре без внешних соединений; `--save-notebook` сохраняет новые выходы. Notebook повторяет доступный анализ отзывов и агрегирует готовые финансовые результаты. **Полный исходный расчёт закупок и себестоимости без закрытых рецептур не воспроизводится.** Изменение модели требует новой проверенной выгрузки автора.

Технические материалы и рецептуры сохранены в отдельной резервной копии вне репозитория. Они исключены из текущего дерева, но старые коммиты, существующие ветки и прежний PR могут содержать их. Удаление текущих файлов не обеспечивает конфиденциальности истории; её очистка — отдельная операция с согласованием. Переписывание истории и force-push в этом изменении не выполнялись.
