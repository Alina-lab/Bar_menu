## 6. Правильный расчёт закупки

Принципиально разделить:

**A. Стоимость использованного сырья** — сколько стоит масса/объём ингредиентов, фактически заложенных в рецептуры по модели.

**B. Денежные затраты на закупку** — сколько нужно заплатить поставщикам с учётом приобретения целых упаковок.

**C. Остаток сырья** — купленное, но не использованное.

Для каждого ингредиента:

`total_needed = sum(required_quantity_for_all_recipes)`

`packs_to_buy = ceil(total_needed / pack_size)`

`purchase_cost = packs_to_buy * pack_price`

`used_cost = total_needed / pack_size * pack_price`

`leftover_quantity = packs_to_buy * pack_size - total_needed`

Особенно важно объединять расход одних и тех же ингредиентов между рецептами.

Пример: малину нужно суммировать для C03 и C12, а не рассчитывать отдельные независимые закупки с округлением каждой партии вверх.

В этой версии считать, что цены за закупочную единицу заданы таблицей выше. Не выдумывать дополнительные скидки без исходных данных.
