# Nastoyka: от исследования рынка к экономике запуска

Какие настойки добавить в меню бара Санкт-Петербурга и сколько будет стоить их выпуск? Проект соединяет анализ публичных отзывов и конкурентного ассортимента с расчётом запуска **десяти вкусов, выбранных автором**. Результат — проверяемая база исследования и воспроизводимая сырьевая модель, а не прогноз продаж.

Авторский план — **60 л / 1 200 порций**. Сценарный первый заказ — **40 002,80 ₽**, средний расход сырья — **30,30 ₽ на 50 мл**. Эта себестоимость не включает затраты на работу бара; равный выпуск не доказывает равный спрос.

## Рынок и данные

Бары, рюмочные и рестораны Петербурга изучались, чтобы увидеть конкурентную карту вкусов и конкретные впечатления гостей. Сохранены 43 карточки заведений; актуальный срез охватывает 30. В базе 368 публикаций, из них 358 проверены, 10 остались неподтверждёнными. Из 468 строк упоминаний для вкусового анализа подтверждены **198 конкретных упоминаний из 108 отзывов**, 114 названий. Источники — Яндекс Карты, Restoclub, 2ГИС, Tripadvisor и Т-Банк Отзывы; возможности доступа различались.

Один отзыв связан с несколькими отдельными упоминаниями. Явные синонимы приводились к общему названию с сохранением исходного; разные сочетания ингредиентов не объединялись. Перечень заказанных вкусов и пять звёзд заведению не превращались в положительную оценку каждого напитка. Строгий срез после ограничений по заведению, уверенности и признакам качества содержит 143 упоминания из 84 отзывов.

Хреновуха и щавель встречаются по 7 раз, по 5 упоминаний положительные. Это небольшой сигнал для дальнейшего изучения. Шесть положительных упоминаний простой томатной пришлись на одно заведение; после строгого отбора осталось одно. Клюква не получила подтверждённых положительных оценок в текущей базе. Частота в отзывах не измеряет продажи, а редкость не доказывает спрос.

Пишущие отзывы не представляют всех гостей; данные исторические и неравномерные. У 275 из 358 проверенных публикаций доступен только видимый фрагмент. Возраст и пол неизвестны; статус приезжего явно указан лишь в пяти отзывах — демографические выводы не делаются.

## Экономика запуска

План — **60 л, 1 200 порций по 50 мл**: по 60 порций каждого вкуса в пятницу и субботу. Дата запуска не назначена. Рецептуры масштабируются по пригодному выходу; потребность общего ингредиента складывается до округления упаковок.

| Показатель | Сценарий автора на 16.10.2026 |
|---|---:|
| Первый заказ сырья | **40 002,80 ₽** |
| Использовано для выпуска 60 л | 36 357,61 ₽ |
| Остаток закупленного сырья | 3 645,19 ₽ |
| Среднее сырьё на 50 мл | 30,30 ₽ |
| Выручка при продаже всех порций | 312 000,00 ₽ |
| Доход после израсходованного сырья | 275 642,39 ₽ |
| Материальная маржинальность | 88,35% |

Ладога — водка, METRO — ягоды и большая часть остальных продуктов, Агропарк СПб — хрен, имбирь и яблоки. [Закупка 16 ингредиентов](data/economics/results/procurement.csv) · [Распределение по поставщикам](data/economics/results/suppliers.csv) · [Расчёты каждого вкуса](data/economics/results/recipe_costs.csv).

Первый заказ дороже производственного расхода: оплачиваются целые упаковки, а не использованные граммы. В запасе остаётся 3 645,19 ₽; его дальнейшая пригодность зависит от хранения и потребности. Общая малина для C03/C12 упрощает закупку, но при текущих фасовках вместе и раздельно нужны шесть упаковок — экономия от округления равна нулю.

**Средние 30,30 ₽ сырья на порцию и материальная маржа не означают чистую прибыль.** Не учтены труд, аренда, налоги, доставка, оборудование и списания. При реализации 50% все 60 л уже произведены: выручка 156 000 ₽, производственный расход не уменьшается. Равный выпуск десяти вкусов не гарантирует равный спрос. При доле премиальных продаж 35% запаса 240 премиальных порций не хватит для реализации всех 1 200 порций.

Более высокий выход снижает расход на порцию при прочих равных. Но в сценарии выхода +10% для вишни нужны две упаковки, а цена 799 ₽ действует от трёх: обычная цена неизвестна, поэтому стоимость C02 и финансовый итог меню **недоступны**. Лишняя упаковка ради скидки не добавляется. Поля обычной цены требуют источник и дату; неизвестное не заменяется нулём. [Чувствительность](data/economics/results/yield_sensitivity.csv) · [Неполные продажи](data/economics/results/sales_scenarios.csv).

## Ограничения перед запуском

Согласование автором не заменяет измерение выхода, крепости или проверку хранения. У C12 14 дней — наблюдение автора, не подтверждённый безопасный срок. Условия поставки водки, пороги/магазин METRO, свежий необработанный хрен, доставка и минимумы заказов требуют проверки. Цены из старого архива не используются. Подробные технологии и риски — [в отчёте](docs/economics_report.md), формулы — [в методике экономики](docs/economics_methodology.md).

## Итоговая презентация

Главный документ — [nastoyka_menu.ipynb](nastoyka_menu.ipynb): карточки десяти напитков, цены за 50 мл, результаты исследования и экономика. Сохранённые таблицы и PNG видны на GitHub без запуска; Run All в Jupyter обновляет расчёты. [assortment_economics.ipynb](assortment_economics.ipynb) остаётся отдельным техническим документом.

[menu_raw_material_costs.csv](data/economics/menu_raw_material_costs.csv) автоматически формируется тем же расчётом: 16 общих потребностей, поставщики, фасовки, применимые цены, затраты и остатки. В экспорте нет дозировок отдельных настоек и полных рецептов. Это результат модели, его не нужно редактировать вручную. CSV округляет только отображение; итоги рассчитываются до округления.

## Воспроизведение

Python 3.12; Python, pandas, Decimal, openpyxl, Matplotlib, Jupyter и pytest. Расчёт работает без внешней сети и ключей. На Windows команды те же; для первичной установки зависимостей нужен интернет.

```bash
python -m pip install -r requirements.txt
python scripts/economics.py
python -m pytest -q
python scripts/workbook.py validate
python scripts/verify.py
```

`verify.py` заново выполняет оба Notebook в отдельных чистых ядрах, блокирует внешние соединения и сверяет CSV, документы и шесть графиков побайтово. Команда `--write-notebook` дополнительно сохраняет свежие выходы обоих Notebook. [Workflow CI](.github/workflows/ci.yml) запускает эти проверки для PR в main и push в рабочую ветку; фактические результаты доступны во вкладке Checks PR. [Протокол локального аудита](docs/validation.md).

Первичная книга, CSV отзывов и методика защищены SHA256: 14 файлов. 62 прежних экономических артефакта доступны в [архиве с manifest](data/economics/history/README.md); исходные аналитические этапы сохранены. Работа ведётся в `analysis/menu-economics`; PR №1 остаётся Draft, слияние в main не выполняется.
